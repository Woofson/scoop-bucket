# Woofson Scoop bucket

[Scoop](https://scoop.sh) bucket for [Brum](https://github.com/Woofson/brum), the multi-panel file commander by Woofsons Lab.

```powershell
scoop bucket add woofson https://github.com/Woofson/scoop-bucket.git
scoop install brum
```

Start the desktop app from the Start Menu shortcut, or run `brum -s`. Your `config.toml` is kept between updates.

Manifests are updated automatically with each Brum release.
